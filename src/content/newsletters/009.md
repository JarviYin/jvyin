**#1  AI agent ：agent 能力越来越强，有些网站开始限制 Agent**

本周AI Agent 继续从“能够执行任务”，进入“长期自主工作、跨应用协作、拥有独立身份与权限”的阶段。Google 和 Meta 两家大厂也在本周升级了 agent 的能力。

10 月 12 日，Meta 的 Muse Wonder 上了 Model API。定位是长程 agent：拆任务、派子 agent、调用工具、从错误里恢复，也能做 computer use。上下文 100 万 token。API 价输入 $4、输出 $20。更强的 Wonder Full 不单卖，包在 Muse Code 的高档订阅里。

10 月 13 日，Gemini 4 Argon 对开发者开放。Google 把它定义成做复杂、多步工作的模型：写代码、金融、法律、网络安全、科研。付费 API 的尝鲜价是输入 $2 / 百万 token，输出 $10。Pro 和 Ultra 能在 Gemini app 里用。

但是，梁圣才是本周主角，DeepSeek-V4.1-Flash-1017 是本周 AI Agent 领域最值得关注的更新之一。DeepSeek-V4.1-Flash-1017重点提升了 Agentic Coding、终端操作、复杂任务执行能力，同时降低任务运行时间和输出长度。

DeepSeek 同时开放了自己的搜索和网页抓取 API：Search：每 1,000 次调用 ¥5，比我之前养龙虾用的 brave search便宜多了。

看来我每个月 $160的 coding 成本又要降了，坐等DeepSeek-V4.1 Pro 的升级版。


**#2 On-chain Finance 链上金融**

本周RWA 市场规模达到约 391.8 亿美元，传统机构从门口走进来了，坐稳了。

1/ 欧洲证券及市场管理局（ESMA）于10月15日前后启动针对中央对手方清算机构（CCP）使用代币化抵押品的公开咨询。

核心问题是代币化国债、基金等资产，能否像传统金融抵押品一样，用于衍生品保证金？

这涉及一个潜在的大市场：欧洲清算机构管理的保证金规模达到数千亿欧元。但监管关注的不只是结算速度，还包括违约时的资产处置能力、法律确定性和流动性。

这与 Hyperliquid 的未来发展有直接的概念关联：如果链上金融逐步支持合规证券抵押品，交易平台就有机会从单一稳定币保证金模式扩展到多资产保证金体系。不过，这不意味着相关欧洲证券可以直接成为 Hyperliquid 抵押品。

2/ 10 月 15 日，Ripple Prime 给机构上了 RWA 永续互换。合约参考的是 Trade.xyz 在 Hyperliquid 上挂的永续，覆盖股票、指数、ETF、金属、能源、外汇，一百多个市场，周末也开着。Ripple 自己当交易对手。客户拿到的是价格敞口，不是股票本身。Virtu 已经在用。允许的地区可以用 RLUSD 做抵押。现在走的是 BVI 牌照。Pump.fun也接了hyperliquid 的 builder code，看 Phantom、fomo 他们赚钱眼红了，早该接了。

传统机构已经选择不自己做一条链，他们借 流动性最好的Hyperliquid 的订单簿，自己出牌照、对手方和保证金。

3/ 我把 On-chain Finance 分成四层，资产层决定金融产品供给，资金层决定流动性，信贷层决定资本效率，交易层决定用户和交易流量。

|层级|核心功能|代表项目|核心商业模式|主要壁垒|
|---|---|---|---|---|
|L1 资产层|将资产发行到链上|Ondo、Securitize、Centrifuge|发行费、管理费、服务费|牌照、资产来源、法律结构|
|L2 资金层|提供链上货币与结算|Circle、Tether、Sky|储备收益、支付费、资金服务|规模、信任、分发、监管|
|L3 信贷层|借贷、抵押、期限转换|Aave、Morpho、Maple|利差、协议费、管理费|风控、流动性、资本效率|
|L4 交易层|价格发现、撮合与风险转移|Hyperliquid、Uniswap、TradeXYZ|交易费、清算相关收入|流动性、执行质量、用户网络|

传统金融系统：资产 → 银行存款 → 银行信贷 → 证券交易所

链上金融系统：Tokenized Assets → Stablecoins → DeFi Credit → On-chain Exchanges

机会不一定在发行资产，而在帮助发行机构进行分发。。。
