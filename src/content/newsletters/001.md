# 我的 AI 使用

- **coding agent 切换：** 我的 Claude 账户被封了有一段时间了，上个月开了个 200U/mon 的 Codex 会员，用的 5.6 SOL 最高级别推理使劲蹬，但是还是觉得蠢，而且额度用的快 + 额度重置，感觉被当猴耍，比不上之前用习惯的 Opus 4.8；然后，本周开始直接全面拥抱国产，试了一下 DeepSeek harness（「一切都是插件」我还没玩明白），DeepSeek v4 pro 最高推理强度，做了个个人 newsletter 网站 jvyin.com，前端 UI 审美还不错。经历了从 Cursor - Manus - Claude Code - Codex - WorkBuddy - DeepSeek harness 转了一圈又用回了 Cursor，开了 60U/mon 的 plan。

![Cursor 本周用量](https://jvyin.com/newsletter/ep01/cursor.png)

- **LLM API：** 用了很久觉得 DeepSeek v4 pro 没有 DeepSeek v4 flash 好用，一是贵，二是慢，大部分的场景下 DeepSeek v4 足够。我把 Hermes agent 和其他的 vibe coding 的产品的 LLM 都默认切换成 v4 flash 了。今天 8 月 22 充值 ¥300，估计够用 1-2 周的？

![DeepSeek 近 7 日用量](https://jvyin.com/newsletter/ep01/ds.png)

- 本周五的深圳 AI 线下沙龙分享了我的「AI 定制化健康管理 agent-华佗」，华佗帮我分析近几年的体检报告 + 基因检测报告 + Whoop 手环睡眠运动监控数据，包括补剂推荐，睡眠和运动建议管理等。竟然有两个朋友感兴趣想把这个产品化商业化，其实我就是用 harness agent + tgbot 的组合做的，不过 bio 赛道真的有点意思，可以聊聊看。
- 币安 8 月 20 日推出了 agent OS，作为一个研究 AI trading 快一年的重度 AI 交易用户，也试过 OKX 的 Onchain OS。刚用 Cursor 接入简单看了下还没深入体验，感觉跟币安 Web3 wallet 一样的产品思路，云托管、低门槛。但目前能力广度暂时不如 OKX，优势是对普通用户门槛更低。AI agent 也会是交易所的兵家必争之地，agent OS 会绕过传统 App/网页前端，直接调后端。一旦交易的入口从「用户点界面」变成「agent 调工具」，交易所之间的竞争维度就从 UX（谁界面好用）转向 API 层的 agent 友好度（谁的工具更标准、更易被 agent 发现和调用）。
