# Jarvi — Frontend UI Defaults

Jarvi requested this as the default visual direction for future frontend work. Apply it unless Jarvi explicitly requests another direction for the task.

- Use a pure-white page background and white content surfaces. Keep the canvas white regardless of the device's dark-mode preference.
- Use an understated panda palette: near-black text, neutral-gray secondary text and light-gray separators. Default accents, charts, focus and selected states to black/gray. Avoid red/pink accents and colorful gradients.
- Establish hierarchy with whitespace, readable typography, alignment and thin lines. Remove decorative outer boxes around text, cards and repeated content groups; prefer open rows with occasional fine separators.
- Preserve necessary input/button boundaries, clear focus/selected states and useful table structure. Functional controls must remain easy to identify.
- Keep corner radii small and typography restrained. Avoid oversized slogans, repeated tiny labels, pill collections, heavy shadows and ornamental animations.
- Use DefiLlama and Tokenomist as references for professional information hierarchy and usability, adapted to this neutral and unboxed visual direction.
- Keep the same design language across Home, Products, Research, Newsletter and data pages. Make the main content easy to scan.
- Adapt every frontend change for desktop and mobile. QA navigation, text wrapping, contained table scrolling and touch targets. Fix in-scope issues and report unavailable checks honestly.
- Provide a working local preview for Jarvi to review. Deploy only with explicit deployment authorization; distinguish local checks, deployed state and exercised production behavior.

Confirmed by Jarvi on 2026-10-18: pure white; black/gray panda palette; fine-line hierarchy; remove the homepage text/card outer frames.
